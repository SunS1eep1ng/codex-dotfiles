# 会话记忆库（Session Memory）

本目录用于存放**单次对话/单次润色任务**中动态维护的登记表，并支持**滚动段落摘要**，以降低前后文术语、论点与衔接不一致的风险。

## 何时创建

- **每一轮新的对话**（或用户开启新的润色任务）时，在 `session-memory/` 下**新建一个** Markdown 文件。
- 命名建议：`memory-YYYY-MM-DD.md`；若同一天多次会话，可加序号：`memory-2026-04-12-02.md`。

## 文件里写什么

### 固定登记表

- **已出现过的名词解释**：中文名、缩写、首次出现位置（可选）；约定后文**不再重复**括号释义或英文对照。
- **已解释过的符号与记号**：如 \(I(x)\)、\(\Omega\) 等含义；后文仅写符号，不再重复「其中……表示……」。
- **用户或论文固定的写法约定**（如缩写一律 `DCP（暗通道先验）`）。

### 滚动段落摘要（长文/分块润色时必填）

- 每处理完**一大段**（一节、一组自然段或用户指定块），在**同一文件**中**追加**「已处理段落摘要」。
- 摘要用于：改**后面**段落前快速对齐前文**已定结论、术语与图表引用声称**。
- 具体写法与「轻微自修 / 严重上报」规则见上级 `SKILL.md`「前后文一致性：滚动段落摘要」。

### 待用户处理的严重问题（按需）

- 仅当缺图、缺逻辑、数据矛盾无法代定、引用失效等**严重**情况时填写；轻微问题由 AI 在正文中直接修正，不必列入。

## 与 SKILL 的关系

执行 `aigc-down-skill` 时，应先读取当日对应的 `memory-*.md`（若存在），润色时**遵守已登记约定**，并在分块任务中**维护摘要**。任务结束可将该文件保留作存档，或按用户要求删除。

## 模板

复制 `_TEMPLATE.md` 为新文件后填写；处理过程中随进度**追加**摘要小节。
