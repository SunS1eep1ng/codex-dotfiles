# AIGC-Down-Skill

中文学术论文 AIGC 检测率降低工具，专为专科、本科毕业论文设计。默认 **保量润色**（避免为降 AIGC 把文章改短、改断）；支持 Plain Text / Word 思路的润色，并对 **LaTeX 源文件** 提供「不误改命令与环境」的约束；含 **会话记忆库**（术语 + **滚动段落摘要**）与 **术语缩写规范**，避免后文重复释义、**前后文不一致**，以及不合规范的中英混排。

## 核心功能

- **智能解析检测报告**：支持导入知网、维普等平台的 HTML 格式 AIGC 检查报告，自动提取高风险标注段落
- **针对性改写**：基于真实论文改写实验归纳的规律，将 AIGC 率从 >50% 有效降至 11% 左右
- **学术规范保障**：改写过程中保留核心论证逻辑，维持学术语域，不新增事实、案例、数据
- **保量润色（默认）**：以换句式、换词、移位为主；润色后汉字数原则上不低于原文约 **92%**；仅套话句可删，论证与数据不删。详见 `SKILL.md`「润色档位与保量原则」
- **术语与缩写**：中文术语后避免冗余英文括号；有缩写时优先 **缩写（中文全称）**（如 `DCP（暗通道先验）`），避免「中文（英文全称, 缩写）」式堆叠
- **会话记忆库**：在 `session-memory/` 下为**每次新对话**新建 `memory-YYYY-MM-DD.md`，登记已解释名词与符号；长文分块时**每处理完一大段追加段落摘要**，改后文前先读摘要，**轻微**衔接/术语问题自修，**严重**缺图、逻辑断裂、数据矛盾等才报告用户（见 `SKILL.md`）
- **LaTeX 保护**：不随意修改 `\cite`、`\ref`、`\label`、数学环境配对等；详见 `SKILL.md` 中的 LaTeX 专项规范

## 使用方式

### 1. 提供检测报告

将 AIGC 检查报告文件（.html 格式，推荐）发送给 Agent 助手，工具会自动解析并提取 AIGC 率高的标注段落。

### 2. 会话记忆（推荐）

新任务开始时，在 `session-memory/` 复制 `_TEMPLATE.md` 为当日记忆文件，或在对话中说明「沿用某 `memory-*.md`」。润色过程中把已定义的术语、符号写入表中，避免后文重复解释。

分章节或分批改写时：每完成一大段，向同一文件**追加**「已处理段落摘要」；处理下一段前**先读**该文件，顺带理顺轻微句法/衔接问题。**仅当**缺图、论证不成立、数据互相矛盾且无法代定等严重情况时，再向用户集中报告（详见 `SKILL.md`「前后文一致性」）。

### 3. 风险识别

输出风险识别报告，列出：

- 高风险段落位置
- 命中的 AI 写作模式类型（模式 1–16，编号以 `SKILL.md` 最新版为准）
- 硬约束违反情况

### 4. 确认改写

用户确认后，输出人工化改写版本，并整理为 `.txt` 文件；若为 LaTeX，可按用户要求输出 `.tex` 片段或整文件。

## AI 写作模式识别（编号已重排）

`SKILL.md` 中的 **模式 1–16** 已按 2026 版重新编号（例如：原「理论起笔」与「泛化结论」等对调顺序，并穿插调整其余条目顺序）。执行润色时**以 `SKILL.md` 正文为准**，下列为内容分类速览：

### 内容层面（模式 1–10）

- 泛化结论与「具有重要意义」结尾、段末多余总结、模板化「核心问题」陈述、模糊归因、「首先/其次/再次」编号逻辑、填充短语与过度限定、「此案例印证了」段末套路、被动分析套话、高度对称并列、「依据/基于XX理论」起笔

### 语言层面（模式 11–12）

- 系动词堆砌（回避「是」）、中文 AI 高频词汇

### 风格层面（模式 13–16）

- 过度工整的「三步走」、对仗排比、加粗滥用、破折号滥用或不用

## 改写质量保障

改写完成后进行多维度评估：

| 维度 | 评估标准 |
|------|----------|
| 直接性 | 直接陈述，不绕圈 |
| 节奏 | 长短句交替，有变化 |
| 真实性 | 像真实学者表达 |
| 信息密度 | 每句话承载信息 |
| 学术规范 | 归因具体，限定合理 |
| 抗检测性 | 模式规律性被打破 |

自检清单中还包含：**术语与记忆库**、**LaTeX 完整性**（若适用）。

## 适用范围

- **文档类型**：专科、本科毕业论文
- **语言**：中文学术写作
- **报告格式**：HTML 格式（推荐）的 AIGC 检查报告
- **LaTeX**：见 `SKILL.md`「LaTeX 源文件专项规范」

## 使用提示

1. 提供完整的 HTML 检测报告可获得更精准的段落定位
2. 改写会保留原文核心意思，不改变论证逻辑与学术观点
3. **若希望明显压缩篇幅**，需明确说「深度改写」或「可压缩」；否则 Agent 按默认保量执行
4. 如需特定风格调整，可在改写前说明偏好
5. 首次出现的缩写建议写成 **缩写（中文全称）**；后文勿重复括号释义（配合 `session-memory/`）
6. 润色 `.tex` 时勿改动引用键与数学环境；不确定处标注人工核对
7. 长文务必维护 `memory-*.md` 的滚动摘要，减少前后术语与论点不一致
